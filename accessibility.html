Accessibility

Care paperwork should be usable by the person doing the caring.

Steady Paws is designed toward WCAG 2.2 Level AA for the website experience, with keyboard access, visible focus, readable contrast, semantic structure, reduced-motion support, and automated accessibility checks in the production build.

Accessible web worksheets

Every tailored care form has an HTML worksheet in addition to the printable PDF. The web worksheet uses real headings, labels, fieldsets, table headers, and form controls so it works more naturally with screen readers, keyboard navigation, zoom, and browser text settings.

About the printable PDFs

The PDFs are designed primarily for printing and handwriting. They may not provide the same assistive-technology experience as the HTML worksheets. If a PDF is difficult to use, choose the accessible web worksheet beside that download and print it from your browser if you need a paper copy.

Photo personalization is optional

You never need to add a name or photo to get the care paperwork. The plain PDF and accessible HTML worksheet remain available without personalization.

Accessibility is an ongoing quality requirement

Automated tools can catch many problems, but they cannot prove legal compliance or reproduce every assistive-technology experience. Steady Paws keeps accessibility checks in its release gate and treats barriers as production defects.
