# Steady Paws

A lightweight, privacy-conscious static site for cat owners managing chronic conditions, starting with feline diabetes.

## Production goals

- Clear, calm information architecture
- Mobile-first and keyboard-accessible UI
- No framework or build step
- No account, analytics, or health-log collection in the current version
- Direct printable resources
- Explicit boundary between organizational tools and veterinary medical advice

## Deploy on Netlify

1. Import this GitHub repository into Netlify.
2. Netlify will read `netlify.toml`; no build command is required.
3. Publish directory is the repository root (`.`).
4. After Netlify assigns the final public domain, add canonical and sitemap URLs in a follow-up SEO pass.

## Key files

- `index.html` - homepage
- `styles/` - split CSS kept small and maintainable
- `downloads/diabetic-cat-tracker.pdf` - printable two-page tracker
- `netlify.toml` - static deploy and security headers
